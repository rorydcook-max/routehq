TWICE Commerce na ang tawag sa Rentle ngayon. Sabi ng documentation ng TWICE, ine-export ng bawat table sa admin nito ang kasalukuyang view sa isang click, kasama ang mga filter, sort at nakikitang column mo, kaya ipakita muna ang lahat ng column na gusto mo bago mag-export.

Kilala ng RoveHQ ang mga order export ng TWICE (customer, line item, presyo, stage, sales channel) at ang mas lumang order export ng Rentle na may store, oras ng simula at tapos, customer at total, at binabasa ang bawat order bilang booking. Kilala rin nito ang Payments report sa mga column nito (petsa ng bayad, uri, paraan, total), at binabasa ang bawat bayad bilang perang pumasok o lumabas.

Nagdedesisyon pa? Basahin ang [ang paghahambing namin ng Rentle (TWICE Commerce na ngayon) at RoveHQ](/guides/rentle-vs-rovehq).

## Libreng import

Libre ang pag-import sa bawat plan. Kilala ng RoveHQ ang mga export ng TWICE Commerce at Rentle at binabasa agad ang mga ito.
