Sabi ng knowledge base ng HQ, puwedeng i-export sa Excel ang bawat table at report sa system. Kilala ng RoveHQ ang reservation at vehicle export ng HQ sa mga heading nito (petsa at lugar ng pick-up at return, vehicle class, plaka, odometer).

## Paano lumilipat ang mga status

- Ang mga reservation na **Open** at **Pending** ay nagiging paparating na booking.
- Ang mga reservation na **Rental** ay nagiging rental na nakalabas ngayon.
- Ang mga reservation na **Completed** ay nagiging nakaraang rental.
- Ang **Quote**, **Cancelled** at **No Show** ay nakalista pero hindi isasama maliban kung i-tick mo.

Magkahiwalay na lumilipat ang total na bayad at ang security deposit, kaya hindi kailanman mabibilang na kita ang deposit na hawak mo.

Nagdedesisyon pa? Basahin ang [ang paghahambing namin ng HQ Rental Software at RoveHQ](/guides/hq-rental-software-vs-rovehq).

## Libreng import

Libre ang pag-import sa bawat plan. Kilala ng RoveHQ ang mga export ng HQ Rental Software at binabasa agad ang mga ito.
