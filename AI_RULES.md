# AI Development Rules

- Always inspect the current implementation before changing code.
- Make the smallest possible change required.
- Do not rewrite unrelated files.
- Do not remove existing functionality unless explicitly instructed.
- Do not change database schema without explaining the migration.
- Do not modify authentication, permissions, or environment variables unless the task requires it.
- Preserve existing UI patterns and naming conventions.
- After changes, explain exactly what changed.
- After changes, explain how to test the change manually.
- If uncertain, ask before making destructive changes.
- Prefer incremental changes over large rewrites.
- Keep the app in a working state after every task.
