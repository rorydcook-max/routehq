Inilalarawan ng Rental Car Manager ang Bookings Export bilang data dump para suriin sa spreadsheet, kaya magandang paraan ito para lumipat. Kilala ito ng RoveHQ sa mga heading nito.

## Paano lumilipat ang mga status

- Ang **Reservation** ay nagiging paparating na booking.
- Ang **Hired** ay nagiging rental na nakalabas ngayon.
- Ang **Returned** ay nagiging nakaraang rental.

Hindi rin kasama sa export ang mga column na itinago mo sa report, kaya ipakita muna ang lahat bago mag-export.

Nagdedesisyon pa? Basahin ang [ang paghahambing namin ng Rental Car Manager at RoveHQ](/guides/rental-car-manager-vs-rovehq).

## Libreng import

Libre ang pag-import sa bawat plan. Kilala ng RoveHQ ang mga export ng Rental Car Manager at binabasa agad ang mga ito. Makikita mo ang bawat sasakyan, booking at bayad bago may ma-save, at puwede mong bawiin ang buong import sa loob ng 30 araw. Ayaw mong gawin ito mismo?
